# Grantora Premium Frontend

React + Vite prototype for Grantora.

## Run
```bash
npm install
npm run dev
```

Routes:
- `/` landing page
- `/login` role selection
- `/dashboard/admin`
- `/dashboard/beneficiary`
- `/dashboard/officer`

This is a frontend-only UI prototype. Login role cards navigate to dashboard previews; authentication and backend API integration are not yet implemented. Scheme and dashboard data is illustrative.
